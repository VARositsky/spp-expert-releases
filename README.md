# СПП-Эксперт

**СПП-Эксперт** — цифровая платформа для подготовки производственного персонала электроэнергетических предприятий к проверке знаний и аттестации.

Приложение объединяет локальные билеты конкретного подразделения, подготовку с проверкой ответов, экзамены и нормативные материалы. Сотрудники могут работать с компьютера или мобильного устройства; администраторы — актуализировать учебную базу и управлять доступом к аттестации.

**[Скачать последнюю сборку](https://github.com/VARositsky/spp-expert-releases/releases/latest)**

## Возможности

| Роль | Основные действия |
| --- | --- |
| Сотрудник | Подготовка по билетам, поиск вопросов, просмотр нормативных материалов, экзамены и своя история |
| Проверяющий | Оценка письменных ответов, комментарии и завершение проверки работ |
| Администратор | Пользователи, редактор, импорт и публикация банков, допуски и результаты сотрудников своей организации |

В подготовке ответы проверяются сразу. В аттестации варианты ответов оценивает сервер, письменные ответы — проверяющий. Программы с пометкой «ПРОБНЫЙ» предназначены для знакомства с приложением; их результаты не являются официальной аттестацией.

## Скачать и установить

Готовые пакеты находятся в разделе [Releases](https://github.com/VARositsky/spp-expert-releases/releases). Для текущих серверных сборок нужна учётная запись организации; данные входа выдаёт организатор.

### Windows 10/11 x64

1. Скачайте [SPP-Expert-Windows.zip](https://github.com/VARositsky/spp-expert-releases/releases/latest/download/SPP-Expert-Windows.zip).
2. Полностью распакуйте ZIP в отдельную папку.
3. Запустите `energy_trainer.exe`.
4. Оставьте библиотеки и папку `data` рядом с исполняемым файлом.
5. Подключитесь к интернету и войдите под выданной учётной записью.

### Android

1. Скачайте [SPP-Expert-Android.apk](https://github.com/VARositsky/spp-expert-releases/releases/latest/download/SPP-Expert-Android.apk).
2. Откройте APK на устройстве и при необходимости разрешите установку из выбранного источника.
3. Завершите установку, откройте приложение и войдите под выданной учётной записью.

Текущий Android-пакет использует тестовую подпись. Для обновления поверх прежней версии нужна совместимая подпись. При ошибке установки сначала сохраните нужные локальные данные и сообщите об ошибке организатору.

## Начало работы

### Подготовка

Откройте «Подготовка» → «Обновить», дождитесь загрузки базы и выберите программу и билет. Изучайте вопросы, проверяйте ответы и обращайтесь к нормативным материалам.

После загрузки учебной публикации подготовка доступна без интернета через сохранённый вход или «Подготовку без сети». Для просмотра нормативного PDF соответствующий файл должен быть доступен на устройстве.

### Аттестация

Получите допуск у администратора. Обновите «Аттестацию», выберите доступную программу и билет, подтвердите начало. Проверяйте сохранение ответов сервером и завершите работу кнопкой «Сдать». Статус и итог находятся в «Истории».

Один допуск разрешает одну попытку. Закрытие приложения не останавливает таймер. При обрыве связи восстановите её и отправьте ответы до дедлайна. После сдачи кнопка «В главное меню» возвращает к основным вкладкам; просмотр вопросов сданной работы остаётся доступен.

### Проверка и администрирование

Проверяющий открывает «Проверка», оценивает каждый письменный ответ и завершает проверку. Администратор управляет пользователями, учебной и экзаменационной базами, допусками и просматривает сданные работы во вкладке «Результаты».

В редакторе изменения сохраняются локально. Для выдачи обновлённой учебной базы сотрудникам загрузите её на сервер и опубликуйте учебный выпуск. Учебная и экзаменационная публикации обновляются отдельно; начатые и прошлые попытки сохраняют свой состав.

Для смены роли используйте «Профиль» → «Выйти из учётной записи».

## Обновление

- **Windows:** закройте приложение и распакуйте новую сборку в отдельную папку.
- **Android:** установите новый APK поверх прежней версии при совместимой подписи.

Предыдущие пакеты доступны в [истории релизов](https://github.com/VARositsky/spp-expert-releases/releases). Старые автономные версии могут отличаться от текущей серверной сборки.
