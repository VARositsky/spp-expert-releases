# СПП-Эксперт

**СПП-Эксперт** — цифровая платформа для подготовки производственного персонала электроэнергетических предприятий к проверке знаний и аттестации.

## Скачать приложение

Готовые версии приложения доступны в разделе **Releases**:

👉 https://github.com/VARositsky/spp-expert-releases/releases/latest

### Windows

1. Скачайте файл `SPP-Expert-Windows.zip`.
2. Распакуйте архив в отдельную папку.
3. Запустите `.exe` файл приложения.

> Не запускайте `.exe` отдельно от остальных файлов архива. Для работы Windows-версии необходимы библиотеки и папка `data`, расположенные рядом с программой.

### Android

1. Скачайте `SPP-Expert-Android.apk`.
2. Откройте APK на Android-устройстве.
3. При необходимости разрешите установку приложений из выбранного источника.
4. Выполните установку.

> Android может показать предупреждение об установке приложения не из Google Play. Это стандартное предупреждение при ручной установке APK.

## Возможности

- подготовка по локальным билетам подразделения;
- режим обучения с мгновенной проверкой ответа;
- тестирование по разделам и программам подготовки;
- пояснения и нормативные материалы;
- поиск по базе вопросов;
- отслеживание прогресса;
- административный редактор вопросов и билетов;
- адаптивный интерфейс для мобильных устройств и компьютеров.

## Поддерживаемые платформы

- Windows 10/11 x64
- Android
